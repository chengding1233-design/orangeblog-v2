# OrangeBlog 2.0 静态演示站

这是 [OrangeBlog 2.0](https://github.com/) 的静态演示版本，使用 Vue 3 + Vite 构建，
数据由 PowerShell 脚本从真实后端导出并固化为 JSON，因此**不需要服务器和数据库**即可浏览。

## 能做什么

- 首页推荐分区、最新文章、分类统计、热门标签
- 文章列表：搜索、按分类筛选、按标签筛选、分页
- 文章详情：Markdown 渲染、代码高亮、标签、作者、点赞数、评论数
- 评论与子评论的展示、作者主页

## 不能做什么（需要后端）

登录注册、写文章、评论、点赞、修改资料等写操作都依赖 Spring Boot + MySQL 后端，
静态站点里这些入口会给出提示。

## 本地预览

因为构建时的 base 是 `/orangeblog-v2/`，本地预览要让站点挂在同名子路径下。

## 部署

本仓库根目录就是站点根目录，直接在仓库设置里开启 GitHub Pages（Source = Deploy from a branch，分支 main / 根目录）即可。
